# Proyecto de evaluaciones PHP y MySQL

Este proyecto contiene varias unidades prácticas de PHP y MySQL, con ejemplos de manejo de fechas, formularios, captcha, seguridad, POO y registro de usuarios.

## Estructura principal

- `index.php`: pagina principal del sitio
- `estilos.css`: estilos generales
- `config.php`: configuracion central de la base de datos
- `include/botonera.php`: navegacion del sitio
- `unidades/`: archivos de cada ejercicio y funcionalidad

## Requisitos

- XAMPP o un servidor local con PHP y MySQL
- Base de datos llamada `phpavanzado`
- Usuario MySQL por defecto: `root` sin password

## Como probarlo

1. Copiar esta carpeta dentro de `htdocs` de XAMPP.
2. Iniciar Apache y MySQL.
3. Abrir en el navegador:
   - `http://localhost/base_evaluaciones/`

## Observacion

La base de datos se configura desde `config.php`, para que el proyecto quede mas ordenado y sea mas sencillo de mantener.
